# 寸纸 · A4 照片排版

一个无需后端的照片打印排版工具。照片始终保留在浏览器本地，通过原始文件的 Object URL 预览，不会上传到服务器，也不会在导入时压缩。

## 功能

- 批量导入浏览器支持的照片格式
- 每张照片可锁定宽度或高度，以厘米设置真实打印尺寸
- 按原图比例自动计算另一边尺寸
- 自动换行、自动分页到 A4
- 可调页边距、照片间距和纸张方向
- 根据原图像素与打印尺寸显示 DPI 清晰度提示
- 通过浏览器打印功能导出 PDF

## 本地预览

这是纯静态项目。可以直接打开 `index.html`，或在目录中运行：

```bash
python3 -m http.server 4173
```

然后访问 <http://localhost:4173>。

## 部署到 GitHub Pages

1. 把本目录提交到一个 GitHub 仓库。
2. 在仓库的 **Settings → Pages** 中选择 **Deploy from a branch**。
3. 选择 `main` 分支和 `/ (root)` 目录，保存即可。

## 打印设置

点击“打印 / 导出 PDF”后：

- 纸张选 A4
- 缩放选 100% 或“实际大小”
- 边距选“无”
- 关闭页眉和页脚
- 需要 PDF 时，打印机选择“另存为 PDF”

不同打印机可能存在不可打印边缘。默认 10mm 页面边距通常足够安全。
