# 寸纸 · A4 照片排版

一个无需后端的照片打印排版工具。照片始终保留在浏览器本地，通过原始文件的 Object URL 预览，不会上传到服务器，也不会在导入时压缩。

## 功能

- 批量导入浏览器支持的照片格式
- 每张照片可锁定宽度或高度，以厘米设置真实打印尺寸
- 按原图比例自动计算另一边尺寸
- 自动换行、自动分页到 A4
- 可调页边距、照片间距和纸张方向
- 根据原图像素与打印尺寸显示 DPI 清晰度提示
- 手机端提供独立的“保存图片到相册”入口，通过系统面板存入照片应用
- 可把排版结果下载为每页一张 PNG 图片（A4、300 DPI、无损）
- 手机端可生成多页 A4 PDF，并通过系统分享面板存储到“文件”
- 不支持系统文件分享时自动回退为浏览器下载
- 仍可通过浏览器打印功能直接打印

## 手机保存

添加照片并完成排版后，点击右上角“保存 / 导出”，选择格式；文件生成后再点击“打开系统保存”：

- **保存图片到相册**：每页生成一张 300 DPI PNG。iPhone 在系统面板选择“存储图像”；安卓选择相册或照片应用。
- **下载 PNG 文件**：将每页 PNG 下载到浏览器的下载目录或“文件”应用。
- **保存为 PDF**：生成标准 A4 多页 PDF。手机在系统分享面板中选择“存储到文件”或文件管理器即可。
- 若浏览器不支持文件分享，网站会自动下载文件。

浏览器出于隐私限制，不能绕过用户确认直接写入手机相册；保存动作会通过系统面板完成。如果浏览器不支持文件分享，网站会下载 PNG，用户可以再从“文件”中存入相册。照片和导出过程始终只发生在本机浏览器中。


## 打印设置

点击“打印 / 导出 PDF”后：

- 纸张选 A4
- 缩放选 100% 或“实际大小”
- 边距选“无”
- 关闭页眉和页脚
- 需要 PDF 时，打印机选择“另存为 PDF”

不同打印机可能存在不可打印边缘。默认 10mm 页面边距通常足够安全。
